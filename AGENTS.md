# AGENTS.md

Instructions for Cursor cloud agents working in this repository.

Project overview, architecture, and development commands live in `CLAUDE.md` and `README.md`; those remain the source for other tooling.

## Computer use — forbidden by default

Never use computer use, browser automation, desktop GUI control, or any screenshot/click/type desktop tools unless Eyuel explicitly asked for computer use / browser / desktop GUI for this specific run.

Default to shell, file edits, tests, and APIs only. If a task seems to need a GUI, stop and report that in the PR or final message instead of opening computer use.
